## 프리미엄 (캐릭터별)
- 명성 +50%, LP 하루 30, 포커스 하루 10,000(최대 30,000), 몹 은화·전리품 +50%, 채집량 +50%, 농사 +100%, 판매세 8%→4%. 섬 구매 가능. 첫 구매 시 LP 500, 포커스 30,000.
- 가격 공식 확인 못 함(커뮤니티: 30일 약 $15 또는 3,750 골드). 은화로 골드 구매 가능. Game Pass 연동 시 3일 + 월 125 LP.
- 무료 캐릭터는 포커스가 하루 0. 처음엔 무료로 배우고 채집·정제를 본격적으로 하면 구매 권장.

## Destiny Board / LP
- 행동 반복으로 노드 명성 → 레벨. LP로 가속.
- LP: 프리미엄 하루 30, 모험가 일일 챌린지 LP 10 + T4 지혜의 서, 저널 미션, 상점.
- 한 줄만: 무기 하나 + 방어구 한 벌, 채집 자원 하나를 T6까지. 자원을 자주 바꾸는 게 흔한 실수.

## 전투
- 초보 무기: Battleaxe(자힐·출혈·광역, 저렴, 가장 많이 추천), Druidic/Nature Staff(회복), Light Crossbow(원거리 안전), Dual Swords(단순), Fire Staff(광역).
- 기본 IP: T4 700, T5 800, T6 900, T7 1000, T8 1100, 인챈트 단계당 +100.
- 솔로 순서: 필드 몹·솔로 인캠프먼트·T3 추적 몹·솔로 랜덤 던전 → 비치명 Mists → Hunter 커럽티드(700) → 비치명 팩션전(700) → 노랑 포털 Ancient Lands → Stalker(900)·Slayer(1100) 커럽티드 → Hellgate(그룹, 비치명 700/치명 900) → The Depths(900, 2~3인, 가방만 잃음).

## 채집
- 존별 최고 티어: 파랑 T4, 노랑 T5, 빨강 T6, 검정 T8. 인챈트 노드는 T4부터 .1~.4.
- 지형별 자원: Steppe 생가죽·섬유·광석 / Forest 목재·생가죽·돌 / Swamp 섬유·목재·생가죽 / Mountain 광석·돌·섬유 / Highlands 목재·돌·광석.
- 시작은 몹을 안 잡아도 되는 목재·섬유. 생가죽은 무기 필요.
- 장비: 채집 모자·옷·신발·가방 T4부터. 같은 자원 가방은 무게 감소. 파이는 채집량·적재량 증가. Avalonian 도구는 나중에.
- 진행: T2~T5 파랑·노랑 → T6 노랑·조심스러운 빨강 → T7~T8 빨강·검정·치명 Mists·Roads.
- 수입: 낮은 존 시간당 20만~100만 은화(커뮤니티 추정, UNCONFIRMED).

## 정제·제작·거래
- 보너스 도시: 금속괴 Thetford, 판자 Fort Sterling, 천 Lymhurst, 가죽 Martlock, 석재 Bridgewatch. Caerleon·Brecilien은 정제 보너스 없음.
- 리턴율: 일반 도시 15.2%, 보너스 도시 36.7%, 일반+포커스 43.5%, 보너스+포커스 53.9%. 원자재와 하위 정제품 모두 적용. 일일 생산 보너스 +10/20% 추가 가능.
- 레시피: T2 원자재 1 / T3 2+T2 / T4 2+T3 / T5 3+T4 / T6 4+T5 / T7 5+T6 / T8 5+T7. T4.x는 일반 T3, T5.x+는 같은 인챈트 하위 정제품. 돌은 인챈트 석재 없음(인챈트 돌 → 일반 석재 2/4/8배).
- 포커스 기본 비용(전문화 전): T2 18, T3 31, T4 54, T5 94, T6 164, T7 287, T8 503, 인챈트 단계마다 한 칸 위.
- 시장: 판매 주문 등록 2.5%, 판매세 8%(프리미엄 4%). 구매 주문에 바로 팔면 등록비 없음(UNCONFIRMED).
- 제작소 사용료 = 아이템 가치 × 0.1125 × (영양 100당 요금)/100. 정제품 가치 = 2^(티어+인챈트).
- Caerleon +15%: 채집 장비·도구·음식. Brecilien +15%: 망토·가방·물약 (2023 자료).
- 블랙 마켓: Caerleon NPC, 장비만 삼. 빨강 존 이동 위험.

## 존과 죽음
- 파랑: PvP 없음(팩션 제외), 잃는 것 없음. 노랑: 플래그 켜야 싸움, 잃는 것 없음(기절 90초). 빨강: 플래그·팩션 PvP, 죽으면 장비·가방 전부. 검정·Roads of Avalon: 항상 PvP, 전부 잃음. 주황(The Depths, 노랑 포털 Ancient Lands): 가방만. Mists: 들어간 존 규칙.
- 플래그: 15초 정지.

## 초반 돈벌이
- 채집: 파랑·노랑 T4~T5 → 원자재 판매 또는 정제 (가장 안전).
- 제작·거래: 같은 도시 주문 차익 → 프리미엄 후 보너스 도시 포커스 정제.
- 전투: 필드·솔로 인캠프먼트 → 솔로 던전(시간당 20만~40만, UNCONFIRMED) → Hunter 커럽티드 → 노랑 포털 Ancient Lands.
- 나중(고위험): 블랙 마켓 운송, 치명 Mists, 팩션전.
